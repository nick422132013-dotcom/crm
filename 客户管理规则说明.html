客户管理

1. 角色说明

角色权限
顾问查看负责客户档案、合同和周期信息，确认合同与周期关联。
医生/护士/客服按负责患者范围查看授权资料并参与医疗或服务协同。
区域负责人查看负责区域客户及医护分配情况。
系统管理员查看全量档案和审计信息，维护授权配置。

2. 相关配置页面

2.1 线索管理

  • 线索关联合同签署成功后，生成夫妻档案并保留来源线索 ID。

2.2 合同管理

  • 一对夫妻可有多份并行合同；合同编号是单份合同的唯一标识。

2.3 周期管理

  • 一对夫妻可有多条历史周期；周期以互创周期号标识并与合同建立可追溯关联。

3. 数据来源

3.1 建档来源

来源建档规则
线索转化首份合同签署后生成档案 ID，并关联来源线索 ID。
互创历史同步发现 CRM 尚无该夫妻档案时直接建档，来源线索 ID 可为空。

3.2 外部同步

  • 合同信息来自法大大/合同系统；病历号、周期及医疗事实来自互创/HIS。
  • 档案 ID 由 CRM 生成且全局唯一，不因病历号补齐、后续合同或状态变化而改变。
  • 合同—周期人工确认结果由 CRM 保存，外部同步不得静默覆盖。

4. 列表字段说明

字段展示及取值规则
档案 IDCRM 夫妻档案唯一标识，建议格式为 ARC-YYYYMM-序号。
夫妻患者分别展示女方、男方姓名、年龄、身份证号和电话；年龄根据身份证出生日期实时计算周岁，不单独维护；年龄、身份证和电话均在“基础信息收起”时隐藏，以女方为治疗主线。
病历号夫妻共用，来自互创；尚未建档时显示“—”。
来源分院紧跟病历号展示；有对应线索时，取该线索的“提供分院”，与线索管理中的记录一致；无关联线索时取合同档案中的分院。
治疗状态位于客户状态之前，独立展示治疗中、治疗终止、治疗完成；客户状态为活产时标记治疗完成，否则有进行中合同为治疗中，没有进行中合同为治疗终止。支持上下箭头排序，正序为治疗中、治疗完成、治疗终止。
客户状态仅展示治疗阶段：签约、进周、取卵、移植、验孕、NT、活产；治疗终止不再作为客户状态，支持上下箭头排序。
默认排序列表首次打开及重置筛选后，按创建时间倒序排列，最新创建的客户排在前面。
已签合同数统计该夫妻已签署的全部合同，包含进行中、已完成和已解除的合同。
进行中合同数统计该夫妻合同状态为“进行中”的合同数量。
已做周期数统计该夫妻全部已建立的周期数量，包含结局为“进行中”的周期。
来源线索线索转化档案可追溯来源线索 ID；历史同步档案可为空。
创建时间显示该夫妻第一份合同的签署日期，以签署日期最早的合同记录为准。

5. 状态与操作

5.1 客户状态

顺序状态说明
1签约合同已签署，尚未进周。
2进周已进入治疗周期。
3取卵进入取卵相关节点。
4移植进入胚胎移植节点。
5验孕进入妊娠检测节点。
6NT进入孕早期 NT 检查或随访。
7活产已完成活产结局记录。
  • 客户状态属于夫妻档案；取消、完结等属于周期结局，不得相互替代。
  • 治疗状态判定：客户状态为“活产”时为“治疗完成”；其他客户只要存在至少一份状态为“进行中”的合同即为“治疗中”；没有进行中合同则为“治疗终止”；治疗状态正序为治疗中、治疗完成、治疗终止，倒序为相反顺序。
  • 治疗终止客户的合同状态仍单独显示“已解除”，周期结局及合同解除原因保留在对应历史记录中。客户状态筛选仅包含治疗阶段状态，不包含治疗状态。

5.2 操作说明

  • 查看详情：查看夫妻信息、合同、周期和历史病历；历史记录展示来源、业务时间和同步时间。
  • 查看合同：跳转合同管理并按当前档案 ID 筛选全部合同。
  • 查看周期：跳转周期管理并按当前档案 ID 筛选全部周期。
  • 客诉记录：查看或新增夫妻档案的服务沟通记录。
  • 关联合同与周期：仅在同一夫妻且类型兼容范围内由授权顾问确认，并填写依据。

6. 查询条件

  • 支持按档案 ID、夫妻任一方姓名、身份证号、电话、病历号、来源分院、治疗状态、客户状态、首次签约顾问和客户创建时间段查询。
  • 档案 ID 与病历号支持模糊匹配；来源分院、治疗状态、客户状态和顾问精确匹配；客户创建时间按第一份合同签署日期筛选，起止日期均包含在结果范围内。多个条件按“且”组合。

7. 关键约束

  • 客户管理以一对夫妻为一条档案；档案 ID、线索 ID、合同编号和周期号不得混用。
  • 已签约档案即使尚无病历号也必须进入客户管理，且至少关联一份合同。
  • 同一夫妻可有多份合同和历史周期；同一时点最多一条周期结局为“进行中”。
  • 合同套餐权益与互创周期次数口径独立，不得自动换算或直接抵扣。
  • 自动匹配只能提供合同—周期候选，人工确认结果必须留痕且不得被自动覆盖。
  • 客户管理示例数据共 13 条：6 条治疗中、6 条治疗终止、1 条治疗完成；只有客户状态为“活产”的档案标记为治疗完成。
