客户管理

1. 角色说明

角色权限
顾问查看负责客户档案、合同和周期信息，分配跟进人员、录入跟进记录。
线索管理员查看负责分院的客户信息。
区域负责人查看负责分院的客户信息
医生/护士/客服按负责患者的详情资料。

2. 相关配置页面

2.1 线索管理

  • 线索关联合同签署成功后，根据法大大的合同数据显示客户，即法大大签署合同的才会成为客户。
  • 一对夫妻为一份客户数据

2.2 合同管理

  • 一对夫妻可有多份并行合同；合同编号是单份合同的唯一标识。

2.3 周期管理

  • 一对夫妻可有多条历史周期；周期以互创周期号标识并与合同建立关联关系。

3. 数据来源

3.1 建档来源

来源建档规则
线索转化-法大大合同首份合同合同签署后生成客户 ID，并关联来源线索 ID。

3.2 外部同步

  • 合同信息来自法大大/合同系统；周期及患者详情来自互创/HIS。

4. 列表字段说明

字段展示及取值规则
序号按创建时间逆序排列。
默认排序列表首次打开及重置筛选后，按创建时间倒序排列，最新创建的客户排在前面。
列表滚动横向滚动时固定序号、女方姓名和操作列；表头及单元格内容均保持单行，超出区域通过横向滚动查看。
档案 IDCRM 夫妻档案唯一标识，建议格式为 YYYYMM-序号，即创建日期+序号。后台记录，列表不显示
女方姓名、女方年龄、女方身份证、女方电话姓名后展示女方年龄；年龄根据身份证出生日期实时计算周岁，不单独维护。年龄、身份证和电话均在“基础信息收起”时隐藏。电话以完整文本显示，示例号码为“123456789009”。
男方姓名、男方年龄、男方身份证、男方电话姓名后展示男方年龄；年龄根据身份证出生日期实时计算周岁，不单独维护。年龄、身份证和电话均在“基础信息收起”时隐藏。电话以完整文本显示，示例号码为“123456789009”。
病历号夫妻共用，来自互创；互创未建档时显示“—”。
来源分院有对应线索时，取该线索的“提供分院”，没有的话可自行在跟进人员进行分配；无关联分院显示为“-”。
治疗结局支持上下箭头排序；正序为治疗中、治疗完成、治疗终止；治疗结局指客户的医疗状态，客户移植成功8周后状态即为治疗完成，没有移植成功8周但有合同在进行中为治疗中，其他情况下均为治疗终止
客户状态仅展示最新治疗阶段：签约、进周、取卵、移植、验孕、NT、活产；支持上下箭头排序；治疗终止时保留客户最后的治疗结局。
顾问展示当前负责该夫妻档案的顾问；默认取签署时间最早的合同的顾问，在系统顾问列表存在才能取到，没有的话往后面日期的合同取；合同都没有的情况下取关联线索的顾问；还没有的话显示为“-”； 之后可通过“跟进人员”调整，顾问选项受当前来源分院限制，只能从该分院已配置的负责顾问中选择。
主诊医生展示当前分配的主诊医生；默认取第一个合同的主诊医生，没有的话往后面日期的合同取，都没有显示“-” ；可通过“跟进人员”调整。
试管客服展示当前分配的试管客服；未分配时显示“—”。通过“跟进人员”调整。
海南端上级医生展示当前分配的海南端上级医生；未分配时显示“—”。通过“跟进人员”调整。
海南端周期护士展示当前分配的海南端周期护士；支持多人，姓名以“、”分隔；未分配时显示“—”。通过“跟进人员”调整。
门诊端陪诊护士展示当前分配的门诊端陪诊护士；未分配时显示“—”。通过“跟进人员”调整。
已签合同数统计该夫妻已签署的全部合同，包含进行中、已完成和已解除的合同。
进行中合同数统计该夫妻合同状态为“进行中”的合同数量。
已做周期数统计该夫妻全部已建立的周期数量，包含结局为“进行中”的周期。
创建时间客户创建时间，即该夫妻第一份合同的签署日期

5. 状态与操作

5.1 客户状态

顺序状态说明
1签约合同已签署，尚未进周。
2进周已进入治疗周期。
3取卵进入取卵相关节点。
4移植进入胚胎移植节点。
5验孕进入妊娠检测节点。
6NT进入孕早期 NT 检查或随访。
7活产已完成活产结局记录。
  • 客户状态属于夫妻档案；取消移植、完结等属于周期状态，不得相互替代。
  • 治疗结局判定：客户状态为“活产”时为“治疗完成”；其他客户只要存在至少一份状态为“进行中”的合同即为“治疗中”；没有进行中合同则为“治疗终止”。治疗结局可单独排序，正序为治疗中、治疗完成、治疗终止，倒序为相反顺序。
  • 治疗终止客户的合同状态仍单独显示“已解除”，周期状态及合同解除原因保留在对应历史记录中。客户状态筛选仅包含治疗阶段状态，不包含治疗结局。

5.2 操作说明

  • 客户列表操作显示“跟进人员”和“跟进记录”；“跟进人员”使用蓝色主按钮。操作区最多显示 4 个按钮，超过时显示前 3 个操作及“更多”，其余操作放入“更多”菜单。
  • 点击“跟进人员”打开“分配跟进人员”弹窗。弹窗字段顺序为：来源分院、顾问、主诊医生、试管客服、海南端上级医生、海南端周期护士、门诊端陪诊护士。来源分院为必选项；顾问为必选单选项，选项随来源分院变化，仅显示分院管理中已配置的负责顾问。来源分院没有选择时，顾问不可选择，应先维护分院。
  • 跟进人员中的医生、护士、客服人员均来自相应角色的用户列表
  • 确认分配后更新客户档案当前来源分院、顾问及对应医护/客服分配；分配记录保存调整前后的来源分院、顾问、主诊医生和陪诊护士，并提示分配结果。客户详情及客户管理列表中的来源分院和顾问同步显示当前分配值。
  • 查看详情：查看夫妻信息、合同、周期和历史病历。
  • 查看合同：跳转合同管理并按当前档案 ID 筛选全部合同，通过夫妻身份证确认关联的合同。
  • 查看周期：跳转周期管理并按当前档案 ID 筛选全部周期，查看所有合同关联的周期。
  • 关联线索：位于客户列表“更多”菜单；有来源线索 ID 时跳转线索管理并定位对应线索记录，无来源线索时提示“无关联线索”，不跳转。
  • 跟进记录：查看或新增夫妻档案的服务沟通记录，类型字典维护。

5.3 查看详情弹窗

  • 弹窗标题显示“女方姓名-男方姓名｜查看详情”；弹窗宽高保持固定，内容较长时在弹窗内容区滚动，不随内容高度变化。
  • 标题栏只保留夫妻姓名标题和关闭按钮。
  • 详情页签为：总览、门诊病历、门诊医嘱、门诊检验、门诊检查、互创病历、周期情况、费用。
  • 总览页最先显示“基本信息”，以女方、男方两张卡片分别展示姓名、性别、年龄和身份证号。
  • “客户资料”紧随基本信息展示，包括病历号、来源分院、治疗结局、客户状态、顾问、主诊医生、试管客服、海南端上级医生、海南端周期护士、门诊端陪诊护士。海南端上级医生与海南端周期护士是两个独立字段；门诊端只显示陪诊护士。资料项按四列等宽对齐，间距一致，空间不足时换行。
  • 客户资料之后再展示合同信息和周期信息。

合同信息

  • 多份合同使用同一张表格展示，每行一份合同，按签署时间倒序排列。
  • 展示字段依次为：签署时间、合同名称、合同金额、合同时效、优惠内容、合同状态、结束类型、试管医院。
  • 保险、定制、变更等合同标识可紧跟合同名称展示。
  • 合同信息表在弹窗内容区内完整排布，不显示横向滚动条。

周期信息

  • 周期信息按合同分组；显示合同状态；每条周期单独占一行。每个合同下的周期按统计日期倒序排列，统计日期为空的周期排在有日期的周期之后。
  • 周期表字段依次为：周期类型、周期阶段、周期状态、取消原因、妊娠结局、进周日期、取卵日期、移植日期、统计日期。日期字段统一放在最后，顺序固定。
  • 周期状态显示“进行中”“完结”或“取消移植”；“取消移植”周期显示取消原因，其他周期该列显示“-”；“完结”周期显示妊娠结局，妊娠结局为“未妊娠”“临床妊娠”或“生化妊娠”，其他周期该列显示“-”。周期阶段单独展示进周、取卵、移植或验孕阶段。

6. 查询条件

  • 支持按夫妻任一方姓名、身份证号、电话、病历号、来源分院、治疗结局、客户状态、首次签约顾问和客户创建时间段查询。
  • 档案 ID 与病历号支持模糊匹配；来源分院、治疗结局、客户状态和顾问精确匹配；客户创建时间按第一份合同签署日期筛选，起止日期均包含在结果范围内。多个条件按“且”组合。

7. 关键约束

  • 客户管理以一对夫妻为一条档案；档案 ID、线索 ID、合同编号和周期号不得混用。
  • 已签约档案即使尚无病历号也必须进入客户管理，且至少关联一份合同。
  • 同一夫妻可有多份合同和历史周期；
  • 同一时点最多一条周期状态为“进行中”。
